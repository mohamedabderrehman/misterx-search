# النشر وحل المشكلات

## التاريخ

مشروع لعرض هندسة البحث. تستخدم الأمثلة العامة سجلات مولدة ومصرحاً بها فقط؛ لا تُنشر مجموعات المصدر أو النتائج الخاصة.

## البيئة المحلية

استخدم PHP 8.1 أو أحدث مع mysqli وامتداد Redis الاختياري. صدّر متغيرات env.example إلى PHP: قاعدة مؤقتة DB_* وJWT_SECRET جديد وDEMO_MODE=1 وDEMO_PASSWORD. شغّل OpenSearch مستقلاً واضبط المضيف والمنفذ والبروتوكول والفهرس portfolio_records. Redis للتخزين المؤقت الاختياري. اجعل LEAKED_DATA_PATH لمسار العينات المولدة المصرح بها فقط؛ الاسم القديم لا يجيز بيانات خاصة. تستخدم الفهرسة fixtures/generated.jsonl.

## تشخيص الأعطال

ابدأ بالتأكد من إصدار اللغة والامتدادات وتثبيت القفل، ثم اتصال قاعدة البيانات وترتيب مخططها ومتغيرات العملية. افحص عنوان API من الجهاز الفعلي لا عنوان localhost الخاص بجهاز آخر. شغل PHP للمسارات الديناميكية والموجه المحلي المرفق حيث يوجد؛ لا ينفذ خادم ثابت ملفات PHP. أبق تحقق TLS فعالاً، ولا تعالج فشل المزود بإظهار نجاح. لا تعِد إرسال نتائج غير مؤكدة دون مراجعة. في Windows أوقف العملية التي تستخدم مخرجات البناء أو محرك Prisma قبل الاستعادة.

لا تُنشر أرقام أداء للفهرسة قبل تنفيذ فحوص OpenSearch والقياس الاصطناعي. تبقى أعطال Redis وOpenSearch والصفحات واتساق مسارات الملفات والفهرسة حدوداً للإصدار. تُستخدم بيانات اصطناعية مصرح بها فقط.

حذف مفتاح من الشيفرة لا يلغيه عند المزود. يجب تدوير بيانات النشر القديمة بشكل مستقل؛ لم يُثبت تدويرها في هذا العمل.
